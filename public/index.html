ESP32 LED Color Game

Install the game on a classic ESP32 DevKit V1.

Use Google Chrome or Microsoft Edge on a computer. This page must be served over HTTPS.

Before installing

  1. Use a USB data cable and connect the ESP32.
  2. Click Install firmware and select its serial port.
  3. If the board is not detected, hold BOOT, tap EN, then try again.

This replaces the firmware currently on the board. The game uses a 33-pixel WS2812/NeoPixel strip on GPIO 13 and buttons on GPIO 12, 14, and 27.
